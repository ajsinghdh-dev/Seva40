# Launch guide

Deployment, Supabase, Google OAuth, environment variables, and release verification are documented in [DEPLOYMENT.md](DEPLOYMENT.md).

The production application is [https://seva40.vercel.app](https://seva40.vercel.app).

Before calling a release complete, run the local typecheck, automated tests, and production build, then verify both student and committee Google sign-in paths on the hosted domain. Test the complete evidence journey with separate accounts and confirm the iPhone and desktop layouts.
