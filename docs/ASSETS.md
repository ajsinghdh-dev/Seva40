# Seva 40 visual assets

The supplied `IMG_6427.JPG` is a visual reference for the dashboard’s dark cards, orange accents, icon rail and arrangement. It is not embedded or redistributed.

The generated kitchen image has been removed at the user’s request. The dashboard and task detail panels use charcoal CSS backgrounds. Bowl, camera, logbook and progress graphics are CSS/SVG interface assets; the brand mark is an original SVG. Icons use Lucide under the ISC license.

DM Sans is self-hosted in `public/fonts`; its SIL Open Font License is included as `public/fonts/OFL.txt`. Font rendering does not send requests to Google.
